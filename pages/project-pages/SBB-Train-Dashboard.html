SBB Train Dashboard

SBB Train Dashboard is an interactive EDA dashboard for average daily train frequencies across SBB route sections in Switzerland, by month (2024-2025).

Description

We built this project in a team of three for a Data Science course at the University of Bern, using a real-world dataset published by SBB. It contains the monthly average daily number of trains, divided into passenger and freight trains.

There was no fixed research question that we wanted to answer - the goal was rather to practice a part of the data science workflow by preparing and exploring the dataset, and building something usable along the way. It also gave me the chance to practice team collaboration with GitHub and focus on reproducibility.

Learnings

In this project, it was the first time that I worked with a setup where I had to think about reproducibility more explicitly, since in my previous projects with Unity and Flutter, it was handled automatically by the framework. We focused on a reliable project setup (without going as far as containerizing it with Docker) by using Poetry for dependency management and writing a clear README.

For collaboration, we used Git and followed best practices such as working with separate branches and pull requests.

On the data side, I learned how much small representation choices affect interpretability, and to be careful when handling missing values - for example switching from sums to averages where sums were misleading, because missing values were treated as zero.

The coolest feature in my opinion is the rolling mean option to smooth out graphs, because it makes it much easier to see the underlying trend. The first chart shows the raw monthly data and the second one applies a 3-month rolling mean (2025, all train types on the route section Tössmühle - Tössmühle Ost):

We get a particularly interesting insight from the data when comparing the 2024 passenger trains of the sections Gotthard Nord (Spw) - Airolo and Rynächt (Abzw) - Sedrun SMF. The traffic patterns of these two sections are strongly complementary, with a clear shift after August 2024. This is due to the reopening of the Gotthard Base Tunnel on September 2nd, 2024, which restored the normal routing between Rynächt and Sedrun and shifted traffic away from the alternative route via Airolo.

What I Would Improve Today

After setting up the project structure, I only tested the project setup on my own existing repository. At first, it didn't work for my teammates. Testing the setup on a new repository before sharing it with the team would have caught the problem earlier and saved everyone some debugging time.
